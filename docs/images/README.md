# Demonstration screenshots

These images were generated from the standalone Qt 6.4.2 build on Linux using
only disposable sample data, including the example's virtual memory files.
No production service or personal file listing is
shown. UI strings are currently predominantly Chinese; sample filenames and
places are English. The installed Qt standard icons and system fonts are used.
No icon theme or font files are bundled here.

Regenerate the visual scenarios with `tests/run_visual_suite.py`; see
[TESTING.md](../TESTING.md). A successful screenshot run proves that images were
saved, not that every interaction is behaviorally correct.

`embedded-example.png` and `memory-io-example.png` come from the complete example
windows' `--screenshot PATH` option. See [EXAMPLES.md](../EXAMPLES.md); their
behavioral smoke checks run separately from screenshot review.
